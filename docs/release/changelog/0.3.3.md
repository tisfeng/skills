# v0.3.3

- 发布日期：2026-09-10

## 修复

- 统一 `git-commit`、`review-pr`、`submit-pr` 与 `worktree-rebase-merge` 的提交预览、暂存范围和状态复验边界，并恢复 PR 提交的默认 Issue 策略与审查重点。

## 变更

- 移除专用 `git-delivery` 子代理，改由当前模型直接通过对应 Skill 完成本地提交与 worktree 集成。
- 复用同一内容快照上的有效规划、验证和仓库元数据证据，减少工作流中的重复委派与查询。

## 升级

- 安装器不会自动删除旧版 `git-delivery`。升级前请删除对应安装目录中的 `agents/git-delivery.toml`，并从 `agents-lock.json` 的 `agents` 对象移除 `git-delivery`；暂不清理时，只更新仍存在的角色：`npx @tisfeng/codex-agents update --agent planner --agent reviewer --agent tester`，全局安装需追加 `--global`。
