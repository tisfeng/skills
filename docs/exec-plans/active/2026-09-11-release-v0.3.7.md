- main CI 失败时不创建 tag；公开 tag 校验失败且需要源码修复时使用下一版本，不移动 tag。
- GitHub Release 创建失败时只恢复 Release 阶段，仍使用精确 tag 标题与 GitHub 默认生成正文。
- 发布完成但隔离安装失败时如实报告，修复使用新版本。
