## 风险与决策

- main CI 失败时不创建 tag；修复后重新冻结候选。
- 已公开 tag 后若需修改源码，改用下一版本，不移动 tag。
- npm 状态不明时先查询 registry 与 workflow，不重复 publish；npm 已成功而 Release 失败时只恢复
  Release 阶段。
- 旧安装保留 `git-delivery` lock 条目时，无选择器更新会失败；发布日志明确清理和选择性更新方法。
