## 背景

## 目标与范围

- 目标结果：发布 v0.10.0，随后将本地消费项目的 `tisfeng/skills` 依赖升级至该版本。
- 允许修改路径：上游版本日志和发布记录；下游受管 Skill、lock、仍有效的依赖说明、关联校验配置及任务记录。
- 同任务 history：`docs/histories/2026-11/2026-11-27-release-v0.10.0.md`
- 用户限制：先发布，随后升级消费项目。下游升级按各仓库规则本地交付。
- 非目标：项目产品代码、独立来源的 Skill、全局安装与历史记录中的旧版本引用。
- 验收标准：发布提交与远端 tag 一致，Release 标题与正文通过核验，固定 tag 隔离安装成功，下游受管依赖与隔离安装快照一致。

## 工作计划

1. 检查上一版本到当前 HEAD 的差异、远端状态和发布工作流，编写版本日志。
2. 运行发布验证矩阵，提交并推送候选，等待该 SHA 的 main 校验成功后推送 annotated tag。
3. 核验 Release 与远端 tag，用固定 ref 隔离安装六项 Skill。
4. 同步下游消费者的受管资产及当前规则，验证后逐个提交，再归档上游发布记录。
